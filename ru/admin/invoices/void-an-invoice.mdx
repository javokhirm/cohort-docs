Аннулируйте счёт, чтобы отменить его полностью — например, если он создан по ошибке или не на того ученика. Аннулировать счёт можно на любой стадии, даже уже оплаченный.

По умолчанию аннулировать счета могут владелец и администратор.

<RoleHint />

<Tip>
  Чтобы отменить только часть суммы счёта, а не весь счёт, [выпустите кредит-ноту](/ru/admin/invoices/issue-a-credit-note) вместо аннулирования.
</Tip>

## Шаги

<Steps>
  <Step title="Откройте счёт">
    В боковом меню выберите **Счета**, затем выберите счёт.
  </Step>
  <Step title="Аннулируйте его">
    Нажмите **Аннулировать**.
  </Step>
  <Step title="Подтвердите">
    Нажмите **Аннулировать счёт**.
  </Step>
</Steps>

<Warning>
  Аннулирование необратимо. Платежи, уже записанные по этому счёту, автоматически не возвращаются — если ученику нужно вернуть деньги, верните сам платёж из истории платежей счёта.
</Warning>
