Шкала оценивания группы определяет, как её преподаватель выставляет оценку за каждое занятие: числом баллов, процентом или буквенной оценкой. У каждой группы в любой момент только одна шкала — она выбирается при создании группы и может быть изменена позже.

## Три шкалы

| Шкала | Как выставляется оценка | Что вы задаёте |
| --- | --- | --- |
| **Баллы** | Число от 0 до выбранного вами максимума — например, из 10. | **Максимум баллов** и, по желанию, **Разрешить половинные баллы** для оценок вроде 7,5. |
| **Проценты** | Целое число от 0 до выбранного вами максимума — обычно 100. | **Максимум (%)** |
| **Буквы** | Буквенные оценки A–F выставляются прямо в ведомости. | Ничего — максимум не задаётся. |

<Note>
  Если не задать шкалу при создании группы, Cohort по умолчанию выбирает **Баллы** из 10. См. [создание группы](/ru/admin/groups/add-a-group).
</Note>

## Смена шкалы позже

Откройте группу, выберите **Шкала оценивания** в меню **Действия с группой**, выберите другой **Тип шкалы** и сохраните.

Смена шкалы не меняет уже выставленные преподавателем оценки — каждая сохраняет ту шкалу, по которой была выставлена. Если в группе уже есть оценки, Cohort сообщает, сколько предыдущих шкал сохраняется, так что полная история группы остаётся читаемой даже после смены.

<Note>
  По умолчанию владельцы и администраторы могут менять шкалу группы в любой момент. Менеджеры могут выбрать её только при создании новой группы.
</Note>
