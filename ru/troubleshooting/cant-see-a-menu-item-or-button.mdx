Каждый сотрудник видит в панели сотрудника только то, что входит в его роль. Пункты бокового меню, вкладки и кнопки, которые не входят в вашу роль, скрыты, а не показаны серыми. Поэтому если коллега видит то, чего не видите вы, дело почти всегда в роли.

## Кто видит пункты бокового меню

Ниже указаны роли по умолчанию. Преподаватели не пользуются панелью сотрудника: они входят в панель преподавателя.

| Пункт меню | Владелец | Администратор | Менеджер |
| --- | --- | --- | --- |
| **Дашборд** | ✓ | ✓ | ✓ |
| **Лиды / Воронка** | ✓ | ✓ | ✓ |
| **Ученики** | ✓ | ✓ | ✓ |
| **Сотрудники и HR** | ✓ | ✓ | ✓ |
| **Курсы** | ✓ | ✓ | — |
| **Кабинеты** | ✓ | ✓ | — |
| **Группы** | ✓ | ✓ | ✓ |
| **Расписание** | ✓ | ✓ | ✓ |
| **Счета** | ✓ | ✓ | ✓ |
| **Платежи** | ✓ | ✓ | ✓ |
| **Тарифные планы** | ✓ | ✓ | — |
| **Биллинговая политика** | ✓ | ✓ | ✓ |
| **Скидки** | ✓ | ✓ | — |
| **Расходы** | ✓ | ✓ | ✓ |
| **Зарплата** | ✓ | ✓ | — |
| **Уведомления** | ✓ | ✓ | — |
| **Филиалы** | ✓ | ✓ | ✓ |

Кнопки и вкладки внутри страниц подчиняются тому же правилу. Например:

- Менеджер может открыть карточку ученика, сотрудника или группы, но не видит действий для их редактирования: менеджер не может менять их после добавления.
- В разделе **Уведомления** вкладку **Настройки** видит только владелец.
- Кнопку **Выдать роль** на странице сотрудника видят только владелец и администратор.

Всё, что может каждая роль, описано на странице [Приложения и роли](/ru/getting-started/apps-and-roles).

## Сообщения, которые вы можете увидеть

<AccordionGroup>
  <Accordion title="«У вас нет прав для доступа к этой странице.»">
    Вы открыли страницу, которая не входит в вашу роль, например по ссылке от коллеги. Вернитесь на страницу из бокового меню или попросите нужную роль (см. ниже).
  </Accordion>

  <Accordion title="«У вас нет прав на это действие.»">
    Cohort отклонил действие, которое ваша роль не разрешает. Может появиться и сообщение «У вас нет прав для выполнения этого действия.» Обычно так бывает, если ваша роль изменилась, пока страница была открыта. Обновите страницу, и на ней останется только то, что вам доступно.
  </Accordion>

  <Accordion title="Мне выдали новую роль, но ничего не изменилось">
    Панель сотрудника проверяет вашу роль при загрузке страницы. Обновите страницу или выйдите и войдите снова, и новые разделы появятся.
  </Accordion>

  <Accordion title="«У вас нет необходимой роли для этого действия.»">
    Это сообщение появляется, если вы входите в приложение не для вашей роли, например преподаватель пытается войти в панель сотрудника. См. [Вход в систему](/ru/getting-started/sign-in).
  </Accordion>
</AccordionGroup>

## Получите нужный доступ

Обратитесь к владельцу или администратору центра. По умолчанию они могут выдать сотруднику другую роль:

<Steps>
  <Step title="Откройте сотрудника">
    В боковом меню выберите **Сотрудники и HR**, затем выберите сотрудника.
  </Step>
  <Step title="Откройте его роли">
    Откройте вкладку **Роли** и нажмите **Выдать роль**.
  </Step>
  <Step title="Выберите роль и филиалы">
    В поле **Роль** выберите **Преподаватель**, **Менеджер** или **Администратор**. В разделе **Филиалы** отметьте **Все филиалы** или филиалы, где роль должна действовать.
  </Step>
  <Step title="Сохраните">
    Нажмите **Выдать роль**.
  </Step>
</Steps>

Новая роль добавляется к ролям, которые у человека уже есть. Чтобы забрать роль, на вкладке **Роли** нажмите кнопку × рядом с филиалом, затем **Отозвать**. Роль владельца здесь нельзя ни выдать, ни забрать.

<Note>
  Сотрудник, чья роль действует только в некоторых филиалах, работает только с учениками, группами и счетами этих филиалов.
</Note>
