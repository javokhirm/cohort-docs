Har bir xodim Xodimlar panelida faqat oʻz roliga kiradigan boʻlimlarni koʻradi. Rolingizga kirmaydigan yon menyu bandlari, varaqlar va tugmalar yashiriladi, kulrang holda koʻrsatilmaydi. Shuning uchun hamkasbingiz koʻradigan narsa sizda koʻrinmasa, sabab deyarli har doim rolda boʻladi.

## Yon menyu bandlarini kim koʻradi

Quyida standart rollar keltirilgan. Oʻqituvchilar Xodimlar panelidan foydalanmaydi: ular Oʻqituvchi paneliga kiradi.

| Yon menyu bandi | Egasi | Administrator | Menejer |
| --- | --- | --- | --- |
| **Boshqaruv paneli** | ✓ | ✓ | ✓ |
| **Lidlar / Voronka** | ✓ | ✓ | ✓ |
| **Oʻquvchilar** | ✓ | ✓ | ✓ |
| **Xodimlar va HR** | ✓ | ✓ | ✓ |
| **Kurslar** | ✓ | ✓ | — |
| **Xonalar** | ✓ | ✓ | — |
| **Guruhlar** | ✓ | ✓ | ✓ |
| **Dars jadvali** | ✓ | ✓ | ✓ |
| **Invoyslar** | ✓ | ✓ | ✓ |
| **Toʻlovlar** | ✓ | ✓ | ✓ |
| **Toʻlov rejalari** | ✓ | ✓ | — |
| **Billing siyosati** | ✓ | ✓ | ✓ |
| **Chegirmalar** | ✓ | ✓ | — |
| **Xarajatlar** | ✓ | ✓ | ✓ |
| **Ish haqi** | ✓ | ✓ | — |
| **Bildirishnomalar** | ✓ | ✓ | — |
| **Filiallar** | ✓ | ✓ | ✓ |

Sahifa ichidagi tugma va varaqlar ham shu qoidaga boʻysunadi. Masalan:

- Menejer oʻquvchi, xodim yoki guruh sahifasini ocha oladi, lekin ularni tahrirlash amallarini koʻrmaydi, chunki menejer ularni qoʻshilgandan keyin oʻzgartira olmaydi.
- **Bildirishnomalar** boʻlimida **Sozlamalar** varagʻini faqat egasi koʻradi.
- Xodim sahifasidagi **Rol berish** tugmasini faqat egasi va administrator koʻradi.

Har bir rol nimalarni qila olishi [Ilovalar va rollar](/uz/getting-started/apps-and-roles) sahifasida yozilgan.

## Chiqishi mumkin boʻlgan xabarlar

<AccordionGroup>
  <Accordion title="“Sizda bu sahifaga kirish huquqi yoʻq.”">
    Siz rolingizga kirmaydigan sahifani ochdingiz, masalan, hamkasbingiz yuborgan havola orqali. Yon menyudagi biror sahifaga qayting yoki kerakli rolni soʻrang (quyida koʻring).
  </Accordion>

  <Accordion title="“Sizda bu amalni bajarish huquqi yoʻq.”">
    Cohort rolingiz ruxsat bermaydigan amalni rad etdi. “Ushbu amalni bajarish uchun ruxsatingiz yo'q.” xabari ham chiqishi mumkin. Bu odatda sahifa ochiq turganda rolingiz oʻzgarganda sodir boʻladi. Sahifani yangilang, shunda unda faqat sizga ruxsat etilgan amallar qoladi.
  </Accordion>

  <Accordion title="Menga yangi rol berildi, lekin hech narsa oʻzgarmadi">
    Xodimlar paneli rolingizni sahifa yuklanayotganda tekshiradi. Sahifani yangilang yoki tizimdan chiqib, qayta kiring: yangi boʻlimlar paydo boʻladi.
  </Accordion>

  <Accordion title="“Ushbu amal uchun zarur rolingiz yo'q.”">
    Bu xabar rolingizga mos boʻlmagan ilovaga kirmoqchi boʻlganingizda chiqadi, masalan, oʻqituvchi Xodimlar paneliga kirmoqchi boʻlsa. [Tizimga kirish](/uz/getting-started/sign-in) sahifasiga qarang.
  </Accordion>
</AccordionGroup>

## Kerakli ruxsatni oling

Markaz egasi yoki administratoriga murojaat qiling. Standart holatda ular xodimga boshqa rol bera oladi:

<Steps>
  <Step title="Xodimni oching">
    Yon menyuda **Xodimlar va HR** boʻlimini oching va xodimni tanlang.
  </Step>
  <Step title="Rollarini oching">
    **Rollar** varagʻini oching va **Rol berish** tugmasini bosing.
  </Step>
  <Step title="Rol va filiallarni tanlang">
    **Roli** maydonida **Oʻqituvchi**, **Menejer** yoki **Administrator**ni tanlang. **Filiallar** boʻlimida **Barcha filiallar**ni yoki rol amal qilishi kerak boʻlgan filiallarni belgilang.
  </Step>
  <Step title="Saqlang">
    **Rol berish** tugmasini bosing.
  </Step>
</Steps>

Yangi rol xodimning mavjud rollariga qoʻshimcha ravishda beriladi. Rolni olib tashlash uchun **Rollar** varagʻida filial yonidagi × tugmasini bosing, soʻng **Bekor qilish**ni tanlang. Egasi rolini bu yerda berib ham, olib tashlab ham boʻlmaydi.

<Note>
  Roli faqat ayrim filiallarni qamrab oladigan xodim faqat oʻsha filiallarning oʻquvchilari, guruhlari va invoyslari bilan ishlaydi.
</Note>
