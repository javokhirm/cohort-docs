By default, only owners and admins can add branches.

<RoleHint />

<Note>
  Cohort already created your center's main branch when it joined. Add another branch only if your center has a second physical location.
</Note>

## Add the branch

<Steps>
  <Step title="Open the form">
    In the sidebar, select **Branches**, then select **Add branch**.
  </Step>
  <Step title="Fill in the branch's details">
    Enter **Branch name**, **Short code**, **Address** and **Phone**. **Short code** is a short, unique identifier for the branch — it's shown as the branch's badge in the list, and can't be changed once saved. **Timezone** defaults to Asia/Tashkent.
  </Step>
  <Step title="Mark it as the main branch (optional)">
    Turn on **Main branch** if this is your center's primary campus — it's used as the default wherever a branch is chosen.
  </Step>
  <Step title="Save" />
</Steps>

## What's next

Now that the branch exists, [add a fee plan](/en/admin/fee-plans/add-a-fee-plan) so you can start billing students there. Or go back to [setting up a new center](/en/getting-started/first-time-setup).
