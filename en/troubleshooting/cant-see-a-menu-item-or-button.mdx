Each staff member sees only the parts of the Staff console that their role includes. Sidebar items, tabs and buttons outside your role are hidden, not greyed out. So if a colleague can see something you can't, the difference is almost always your role.

## Who sees each sidebar item

These are the default roles. Teachers don't use the Staff console: they sign in to the Teacher console instead.

| Sidebar item | Owner | Admin | Manager |
| --- | --- | --- | --- |
| **Dashboard** | ✓ | ✓ | ✓ |
| **Leads / Pipeline** | ✓ | ✓ | ✓ |
| **Students** | ✓ | ✓ | ✓ |
| **Staff & HR** | ✓ | ✓ | ✓ |
| **Courses** | ✓ | ✓ | — |
| **Rooms** | ✓ | ✓ | — |
| **Groups** | ✓ | ✓ | ✓ |
| **Schedule** | ✓ | ✓ | ✓ |
| **Invoices** | ✓ | ✓ | ✓ |
| **Payments** | ✓ | ✓ | ✓ |
| **Fee Plans** | ✓ | ✓ | — |
| **Billing Policy** | ✓ | ✓ | ✓ |
| **Discounts** | ✓ | ✓ | — |
| **Expenses** | ✓ | ✓ | ✓ |
| **Payroll** | ✓ | ✓ | — |
| **Notifications** | ✓ | ✓ | — |
| **Branches** | ✓ | ✓ | ✓ |

Buttons and tabs inside a page follow the same rule. For example:

- A manager can open a student, a staff member or a group, but doesn't see the actions to edit them, because managers can't change them once they've been added.
- Under **Notifications**, only the owner sees the **Settings** tab.
- Only owners and admins see **Grant role** on a staff member's page.

For everything each role can do, see [Apps and roles](/en/getting-started/apps-and-roles).

## Messages you might see

<AccordionGroup>
  <Accordion title="“You don't have permission to access this page.”">
    You opened a page your role doesn't include, for example from a link a colleague sent you. Go back to a page in your sidebar, or ask for the role you need (see below).
  </Accordion>

  <Accordion title="“You do not have permission to do that.”">
    Cohort refused an action your role doesn't allow. You might also see "You do not have permission to perform this action." This can happen when your role changed while the page was open. Reload the page so that it shows only what you can do.
  </Accordion>

  <Accordion title="I was given a new role, but nothing changed">
    The Staff console checks your role when the page loads. Reload the page, or sign out and sign in again, and the new items appear.
  </Accordion>

  <Accordion title="“You do not have the required role for this action.”">
    This appears when you sign in to an app that isn't for your role, for example a teacher signing in to the Staff console. See [Sign in](/en/getting-started/sign-in).
  </Accordion>
</AccordionGroup>

## Get the access you need

Ask your center's owner or an admin. By default, they can give a staff member another role:

<Steps>
  <Step title="Open the staff member">
    In the sidebar, select **Staff & HR**, then select the staff member.
  </Step>
  <Step title="Open their roles">
    Open the **Roles** tab, then select **Grant role**.
  </Step>
  <Step title="Choose the role and branches">
    Choose the **Role**: **Teacher**, **Manager** or **Admin**. Under **Branches**, select **All branches** or the branches where they should have it.
  </Step>
  <Step title="Save">
    Select **Grant role**.
  </Step>
</Steps>

A new role is added alongside the roles the person already has. To take one away, on the **Roles** tab, select the × button next to the branch, then select **Revoke**. The owner role can't be granted or taken away here.

<Note>
  Someone whose role covers only some branches works only with those branches' students, groups and invoices.
</Note>
